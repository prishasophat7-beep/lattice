# 7.6 Lubricate the hydraulic clamp hose

_Manual pages not recorded_

Every 1700 hours, lubricate the hydraulic clamp hose and note the result in the machine log. The hydraulic clamp hose must be inspected by a Level 2 technician only. Use only Helix-approved switchs on the hydraulic clamp; others void the service agreement. The hydraulic clamp filter must be inspected by a Level 2 technician only. Use only Helix-approved cables on the hydraulic clamp; others void the service agreement. After any work on the hydraulic clamp, run the self-test from the maintenance menu (about 13 seconds).
