# 31.3 Check the control panel bearing

_Manual pages not recorded_

Use only Helix-approved relays on the control panel; others void the service agreement. Use only Helix-approved gaskets on the control panel; others void the service agreement. Every 2200 hours, check the control panel relay and note the result in the machine log. Use only Helix-approved valves on the control panel; others void the service agreement. Every 1200 hours, check the control panel bracket and note the result in the machine log. After any work on the control panel, run the self-test from the maintenance menu (about 44 seconds). After any work on the control panel, run the self-test from the maintenance menu (about 48 seconds). After any work on the control panel, run the self-test from the maintenance menu (about 24 seconds). If the control panel shows wear above 40 %, verify the sensor before the next shift.
