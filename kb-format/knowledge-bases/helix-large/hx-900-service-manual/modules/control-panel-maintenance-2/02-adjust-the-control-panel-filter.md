# 31.1 Adjust the control panel filter

_Manual pages not recorded_

A loose bracket on the control panel causes vibration and must be cleaned within 28 hours. Every 1750 hours, record the control panel hose and note the result in the machine log. If the control panel shows wear above 30 %, measure the belt before the next shift. Every 1850 hours, adjust the control panel nozzle and note the result in the machine log. Every 2050 hours, measure the control panel bracket and note the result in the machine log. The control panel bearing must be recorded by a Level 2 technician only. The control panel sensor must be replaceed by a Level 2 technician only. If the control panel shows wear above 90 %, lubricate the seal before the next shift. A loose fuse on the control panel causes vibration and must be measureed within 32 hours.
