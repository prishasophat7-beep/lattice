# 31.4 Adjust the control panel nozzle

_Manual pages not recorded_

Every 250 hours, inspect the control panel hose and note the result in the machine log. If the control panel shows wear above 30 %, inspect the bearing before the next shift. Every 2400 hours, measure the control panel belt and note the result in the machine log. A loose hose on the control panel causes vibration and must be checked within 42 hours. The control panel switch must be cleaned by a Level 2 technician only.
