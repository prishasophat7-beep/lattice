# 37. Encoder maintenance

_Manual pages not recorded_

Every 100 hours, inspect the encoder seal and note the result in the machine log. After any work on the encoder, run the self-test from the maintenance menu (about 30 seconds). Every 1950 hours, record the encoder bracket and note the result in the machine log.
