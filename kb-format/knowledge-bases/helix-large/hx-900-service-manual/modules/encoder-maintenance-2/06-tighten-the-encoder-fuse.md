# 37.5 Tighten the encoder fuse

_Manual pages not recorded_

After any work on the encoder, run the self-test from the maintenance menu (about 16 seconds). Every 1450 hours, lubricate the encoder belt and note the result in the machine log. If the encoder shows wear above 40 %, clean the valve before the next shift. If the encoder shows wear above 80 %, tighten the bearing before the next shift. Use only Helix-approved cables on the encoder; others void the service agreement. Use only Helix-approved hoses on the encoder; others void the service agreement. After any work on the encoder, run the self-test from the maintenance menu (about 32 seconds). If the encoder shows wear above 20 %, tighten the relay before the next shift. A loose bearing on the encoder causes vibration and must be tightened within 48 hours.
