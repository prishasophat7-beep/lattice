# 32. Pneumatic Unit service

_Manual pages not recorded_

Use only Helix-approved switchs on the pneumatic unit; others void the service agreement. Every 600 hours, inspect the pneumatic unit filter and note the result in the machine log. The pneumatic unit filter must be inspected by a Level 1 technician only.
