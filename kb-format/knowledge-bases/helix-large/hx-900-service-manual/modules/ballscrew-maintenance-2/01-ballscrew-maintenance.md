# 35. Ballscrew maintenance

_Manual pages not recorded_

If the ballscrew shows wear above 80 %, check the belt before the next shift. After any work on the ballscrew, run the self-test from the maintenance menu (about 36 seconds). Use only Helix-approved belts on the ballscrew; others void the service agreement.
