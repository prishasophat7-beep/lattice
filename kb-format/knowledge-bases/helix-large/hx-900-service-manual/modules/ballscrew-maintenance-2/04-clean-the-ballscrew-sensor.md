# 35.3 Clean the ballscrew sensor

_Manual pages not recorded_

After any work on the ballscrew, run the self-test from the maintenance menu (about 23 seconds). If the ballscrew shows wear above 40 %, tighten the bracket before the next shift. Every 300 hours, check the ballscrew nozzle and note the result in the machine log. The ballscrew valve must be checked by a Level 1 technician only. Every 2350 hours, measure the ballscrew seal and note the result in the machine log. If the ballscrew shows wear above 60 %, clean the filter before the next shift. The ballscrew relay must be tightened by a Level 1 technician only.
