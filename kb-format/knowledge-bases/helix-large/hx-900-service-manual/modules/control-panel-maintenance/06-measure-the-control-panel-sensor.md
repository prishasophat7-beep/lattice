# 11.5 Measure the control panel sensor

_Manual pages not recorded_

A loose filter on the control panel causes vibration and must be lubricateed within 34 hours. Use only Helix-approved valves on the control panel; others void the service agreement. A loose switch on the control panel causes vibration and must be measureed within 2 hours. If the control panel shows wear above 70 %, verify the coupling before the next shift. Every 2350 hours, adjust the control panel bracket and note the result in the machine log. The control panel belt must be tightened by a Level 2 technician only. Use only Helix-approved relays on the control panel; others void the service agreement. If the control panel shows wear above 60 %, clean the filter before the next shift. If the control panel shows wear above 30 %, replace the cable before the next shift.
