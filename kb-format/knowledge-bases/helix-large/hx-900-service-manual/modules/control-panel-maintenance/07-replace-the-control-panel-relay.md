# 11.6 Replace the control panel relay

_Manual pages not recorded_

Every 1500 hours, tighten the control panel belt and note the result in the machine log. If the control panel shows wear above 30 %, clean the hose before the next shift. Use only Helix-approved brackets on the control panel; others void the service agreement. After any work on the control panel, run the self-test from the maintenance menu (about 9 seconds).
