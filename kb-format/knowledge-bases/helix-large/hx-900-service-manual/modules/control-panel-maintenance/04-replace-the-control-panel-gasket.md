# 11.3 Replace the control panel gasket

_Manual pages not recorded_

Every 150 hours, record the control panel valve and note the result in the machine log. A loose filter on the control panel causes vibration and must be checked within 21 hours. A loose switch on the control panel causes vibration and must be checked within 45 hours. After any work on the control panel, run the self-test from the maintenance menu (about 29 seconds). Every 1100 hours, tighten the control panel cable and note the result in the machine log. After any work on the control panel, run the self-test from the maintenance menu (about 48 seconds).
