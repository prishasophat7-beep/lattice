# 11.2 Inspect the control panel hose

_Manual pages not recorded_

Every 1850 hours, tighten the control panel fuse and note the result in the machine log. Every 150 hours, clean the control panel hose and note the result in the machine log. The control panel bearing must be inspected by a Level 1 technician only. A loose nozzle on the control panel causes vibration and must be recorded within 26 hours. A loose nozzle on the control panel causes vibration and must be recorded within 46 hours. Every 2300 hours, verify the control panel fuse and note the result in the machine log. Use only Helix-approved brackets on the control panel; others void the service agreement. Use only Helix-approved couplings on the control panel; others void the service agreement. If the control panel shows wear above 30 %, measure the fuse before the next shift.
