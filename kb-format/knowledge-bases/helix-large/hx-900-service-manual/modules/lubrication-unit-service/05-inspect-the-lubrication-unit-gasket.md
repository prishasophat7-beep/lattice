# 6.4 Inspect the lubrication unit gasket

_Manual pages not recorded_

The lubrication unit switch must be measureed by a Level 2 technician only. Use only Helix-approved switchs on the lubrication unit; others void the service agreement. After any work on the lubrication unit, run the self-test from the maintenance menu (about 48 seconds). After any work on the lubrication unit, run the self-test from the maintenance menu (about 34 seconds). A loose switch on the lubrication unit causes vibration and must be cleaned within 2 hours. If the lubrication unit shows wear above 10 %, inspect the seal before the next shift.
