# 6.6 Replace the lubrication unit bracket

_Manual pages not recorded_

After any work on the lubrication unit, run the self-test from the maintenance menu (about 33 seconds). Every 1700 hours, check the lubrication unit cable and note the result in the machine log. The lubrication unit belt must be replaceed by a Level 1 technician only. The lubrication unit filter must be tightened by a Level 1 technician only. Use only Helix-approved fuses on the lubrication unit; others void the service agreement. The lubrication unit bearing must be checked by a Level 2 technician only. If the lubrication unit shows wear above 10 %, tighten the bracket before the next shift. Use only Helix-approved bearings on the lubrication unit; others void the service agreement. After any work on the lubrication unit, run the self-test from the maintenance menu (about 23 seconds).
