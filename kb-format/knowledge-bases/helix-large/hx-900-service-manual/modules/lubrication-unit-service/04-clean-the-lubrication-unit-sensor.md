# 6.3 Clean the lubrication unit sensor

_Manual pages not recorded_

A loose cable on the lubrication unit causes vibration and must be cleaned within 5 hours. Every 1600 hours, verify the lubrication unit belt and note the result in the machine log. The lubrication unit sensor must be cleaned by a Level 1 technician only. Every 1100 hours, adjust the lubrication unit switch and note the result in the machine log. If the lubrication unit shows wear above 70 %, lubricate the belt before the next shift. If the lubrication unit shows wear above 70 %, lubricate the fuse before the next shift. If the lubrication unit shows wear above 50 %, tighten the bracket before the next shift. If the lubrication unit shows wear above 80 %, adjust the nozzle before the next shift. The lubrication unit nozzle must be adjusted by a Level 1 technician only.
