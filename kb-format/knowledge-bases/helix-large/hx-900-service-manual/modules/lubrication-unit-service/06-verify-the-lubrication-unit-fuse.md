# 6.5 Verify the lubrication unit fuse

_Manual pages not recorded_

A loose fuse on the lubrication unit causes vibration and must be inspected within 3 hours. If the lubrication unit shows wear above 50 %, inspect the bearing before the next shift. Use only Helix-approved filters on the lubrication unit; others void the service agreement. After any work on the lubrication unit, run the self-test from the maintenance menu (about 28 seconds). The lubrication unit coupling must be replaceed by a Level 1 technician only.
