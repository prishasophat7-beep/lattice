# 20.4 Verify the mist collector hose

_Manual pages not recorded_

The mist collector valve must be adjusted by a Level 2 technician only. The mist collector cable must be adjusted by a Level 1 technician only. After any work on the mist collector, run the self-test from the maintenance menu (about 38 seconds). Every 1400 hours, adjust the mist collector cable and note the result in the machine log. After any work on the mist collector, run the self-test from the maintenance menu (about 45 seconds). After any work on the mist collector, run the self-test from the maintenance menu (about 42 seconds). The mist collector fuse must be tightened by a Level 2 technician only.
