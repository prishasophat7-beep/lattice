# 20.6 Adjust the mist collector sensor

_Manual pages not recorded_

Every 2200 hours, tighten the mist collector relay and note the result in the machine log. Use only Helix-approved seals on the mist collector; others void the service agreement. Use only Helix-approved fuses on the mist collector; others void the service agreement. The mist collector seal must be verifyed by a Level 2 technician only. Every 1350 hours, adjust the mist collector valve and note the result in the machine log.
