# 27.2 Verify the hydraulic clamp valve

_Manual pages not recorded_

Use only Helix-approved fuses on the hydraulic clamp; others void the service agreement. The hydraulic clamp belt must be recorded by a Level 2 technician only. The hydraulic clamp coupling must be replaceed by a Level 2 technician only. If the hydraulic clamp shows wear above 60 %, lubricate the valve before the next shift. After any work on the hydraulic clamp, run the self-test from the maintenance menu (about 28 seconds). After any work on the hydraulic clamp, run the self-test from the maintenance menu (about 12 seconds). Every 1900 hours, lubricate the hydraulic clamp nozzle and note the result in the machine log.
