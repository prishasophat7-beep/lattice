# 21.4 Tighten the axis drive seal

_Manual pages not recorded_

Use only Helix-approved fuses on the axis drive; others void the service agreement. Every 1050 hours, check the axis drive hose and note the result in the machine log. Every 1200 hours, inspect the axis drive bracket and note the result in the machine log. If the axis drive shows wear above 50 %, adjust the belt before the next shift. A loose seal on the axis drive causes vibration and must be checked within 2 hours. Every 1050 hours, tighten the axis drive valve and note the result in the machine log. The axis drive gasket must be adjusted by a Level 2 technician only. After any work on the axis drive, run the self-test from the maintenance menu (about 24 seconds). The axis drive sensor must be verifyed by a Level 2 technician only.
