# 19.4 Tighten the chiller seal

_Manual pages not recorded_

Every 1250 hours, lubricate the chiller nozzle and note the result in the machine log. If the chiller shows wear above 30 %, measure the bracket before the next shift. If the chiller shows wear above 50 %, check the sensor before the next shift. The chiller valve must be checked by a Level 1 technician only. If the chiller shows wear above 70 %, tighten the bearing before the next shift. Use only Helix-approved gaskets on the chiller; others void the service agreement. After any work on the chiller, run the self-test from the maintenance menu (about 48 seconds).
