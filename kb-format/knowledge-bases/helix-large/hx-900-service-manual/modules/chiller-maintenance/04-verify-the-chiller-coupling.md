# 19.3 Verify the chiller coupling

_Manual pages not recorded_

Use only Helix-approved switchs on the chiller; others void the service agreement. Use only Helix-approved sensors on the chiller; others void the service agreement. If the chiller shows wear above 50 %, clean the gasket before the next shift. Every 700 hours, verify the chiller coupling and note the result in the machine log. If the chiller shows wear above 40 %, measure the fuse before the next shift. A loose cable on the chiller causes vibration and must be measureed within 22 hours. If the chiller shows wear above 80 %, tighten the gasket before the next shift. Every 1600 hours, adjust the chiller valve and note the result in the machine log.
