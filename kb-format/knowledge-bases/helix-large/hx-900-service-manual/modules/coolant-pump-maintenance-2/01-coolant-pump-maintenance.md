# 23. Coolant Pump maintenance

_Manual pages not recorded_

Every 950 hours, adjust the coolant pump belt and note the result in the machine log. Use only Helix-approved fuses on the coolant pump; others void the service agreement. After any work on the coolant pump, run the self-test from the maintenance menu (about 31 seconds).
