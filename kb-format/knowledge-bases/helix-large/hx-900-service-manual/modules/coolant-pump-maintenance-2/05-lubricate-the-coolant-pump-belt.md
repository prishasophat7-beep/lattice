# 23.4 Lubricate the coolant pump belt

_Manual pages not recorded_

The coolant pump belt must be tightened by a Level 2 technician only. Every 1100 hours, lubricate the coolant pump belt and note the result in the machine log. After any work on the coolant pump, run the self-test from the maintenance menu (about 20 seconds). The coolant pump bearing must be adjusted by a Level 1 technician only. Every 1000 hours, adjust the coolant pump belt and note the result in the machine log. After any work on the coolant pump, run the self-test from the maintenance menu (about 15 seconds).
