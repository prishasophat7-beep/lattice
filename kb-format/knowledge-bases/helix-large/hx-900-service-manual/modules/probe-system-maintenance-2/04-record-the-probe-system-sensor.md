# 29.3 Record the probe system sensor

_Manual pages not recorded_

The probe system switch must be checked by a Level 1 technician only. A loose seal on the probe system causes vibration and must be measureed within 44 hours. Use only Helix-approved seals on the probe system; others void the service agreement. The probe system belt must be inspected by a Level 2 technician only. Every 2400 hours, replace the probe system fuse and note the result in the machine log. If the probe system shows wear above 10 %, clean the valve before the next shift. If the probe system shows wear above 20 %, record the belt before the next shift.
