# 4.2 Lubricate the tool changer nozzle

_Manual pages not recorded_

After any work on the tool changer, run the self-test from the maintenance menu (about 34 seconds). A loose sensor on the tool changer causes vibration and must be replaceed within 31 hours. A loose valve on the tool changer causes vibration and must be lubricateed within 23 hours. Use only Helix-approved hoses on the tool changer; others void the service agreement. The tool changer bracket must be checked by a Level 2 technician only. A loose belt on the tool changer causes vibration and must be adjusted within 40 hours. Use only Helix-approved switchs on the tool changer; others void the service agreement.
