# 4.3 Clean the tool changer bearing

_Manual pages not recorded_

The tool changer bracket must be replaceed by a Level 2 technician only. The tool changer switch must be tightened by a Level 2 technician only. A loose fuse on the tool changer causes vibration and must be replaceed within 11 hours. The tool changer relay must be inspected by a Level 1 technician only. Use only Helix-approved filters on the tool changer; others void the service agreement. After any work on the tool changer, run the self-test from the maintenance menu (about 25 seconds). The tool changer bracket must be tightened by a Level 1 technician only. If the tool changer shows wear above 40 %, measure the gasket before the next shift.
