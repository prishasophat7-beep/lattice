# 4.6 Measure the tool changer hose

_Manual pages not recorded_

The tool changer bracket must be recorded by a Level 1 technician only. If the tool changer shows wear above 90 %, lubricate the belt before the next shift. A loose bearing on the tool changer causes vibration and must be cleaned within 42 hours. After any work on the tool changer, run the self-test from the maintenance menu (about 5 seconds). The tool changer valve must be checked by a Level 1 technician only. After any work on the tool changer, run the self-test from the maintenance menu (about 21 seconds). After any work on the tool changer, run the self-test from the maintenance menu (about 38 seconds).
