# 4.4 Lubricate the tool changer filter

_Manual pages not recorded_

If the tool changer shows wear above 70 %, adjust the gasket before the next shift. A loose nozzle on the tool changer causes vibration and must be replaceed within 48 hours. After any work on the tool changer, run the self-test from the maintenance menu (about 40 seconds). Every 500 hours, check the tool changer gasket and note the result in the machine log. Every 1850 hours, adjust the tool changer bracket and note the result in the machine log. Every 2250 hours, record the tool changer gasket and note the result in the machine log.
