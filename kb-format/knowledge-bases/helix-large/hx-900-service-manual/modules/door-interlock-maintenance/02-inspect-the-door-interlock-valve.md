# 13.1 Inspect the door interlock valve

_Manual pages not recorded_

If the door interlock shows wear above 50 %, tighten the filter before the next shift. The door interlock cable must be recorded by a Level 2 technician only. Every 2150 hours, measure the door interlock gasket and note the result in the machine log. A loose valve on the door interlock causes vibration and must be recorded within 34 hours. After any work on the door interlock, run the self-test from the maintenance menu (about 48 seconds). Every 400 hours, lubricate the door interlock hose and note the result in the machine log.
