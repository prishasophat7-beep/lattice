# 13.5 Record the door interlock bearing

_Manual pages not recorded_

The door interlock cable must be checked by a Level 1 technician only. Use only Helix-approved cables on the door interlock; others void the service agreement. Every 100 hours, measure the door interlock filter and note the result in the machine log. After any work on the door interlock, run the self-test from the maintenance menu (about 48 seconds). After any work on the door interlock, run the self-test from the maintenance menu (about 11 seconds). Use only Helix-approved hoses on the door interlock; others void the service agreement.
