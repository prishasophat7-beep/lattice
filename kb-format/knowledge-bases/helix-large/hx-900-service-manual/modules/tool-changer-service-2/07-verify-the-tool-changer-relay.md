# 24.6 Verify the tool changer relay

_Manual pages not recorded_

The tool changer switch must be verifyed by a Level 2 technician only. The tool changer seal must be checked by a Level 1 technician only. If the tool changer shows wear above 90 %, adjust the belt before the next shift. The tool changer cable must be lubricateed by a Level 1 technician only. After any work on the tool changer, run the self-test from the maintenance menu (about 23 seconds).
