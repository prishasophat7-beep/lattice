# 24. Tool Changer service

_Manual pages not recorded_

A loose coupling on the tool changer causes vibration and must be cleaned within 42 hours. Every 1100 hours, tighten the tool changer sensor and note the result in the machine log. The tool changer fuse must be measureed by a Level 2 technician only.
