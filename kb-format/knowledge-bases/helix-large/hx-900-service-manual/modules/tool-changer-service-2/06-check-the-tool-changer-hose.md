# 24.5 Check the tool changer hose

_Manual pages not recorded_

After any work on the tool changer, run the self-test from the maintenance menu (about 35 seconds). The tool changer fuse must be inspected by a Level 1 technician only. Every 1100 hours, inspect the tool changer bearing and note the result in the machine log. The tool changer bracket must be adjusted by a Level 1 technician only. A loose gasket on the tool changer causes vibration and must be lubricateed within 21 hours.
