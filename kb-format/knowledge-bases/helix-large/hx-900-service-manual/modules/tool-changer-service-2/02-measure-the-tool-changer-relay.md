# 24.1 Measure the tool changer relay

_Manual pages not recorded_

After any work on the tool changer, run the self-test from the maintenance menu (about 12 seconds). Use only Helix-approved valves on the tool changer; others void the service agreement. The tool changer valve must be checked by a Level 1 technician only. Every 2350 hours, replace the tool changer switch and note the result in the machine log. The tool changer coupling must be verifyed by a Level 2 technician only. Use only Helix-approved brackets on the tool changer; others void the service agreement. Use only Helix-approved switchs on the tool changer; others void the service agreement. A loose valve on the tool changer causes vibration and must be lubricateed within 42 hours.
