# 26.3 Record the lubrication unit seal

_Manual pages not recorded_

If the lubrication unit shows wear above 50 %, measure the fuse before the next shift. A loose fuse on the lubrication unit causes vibration and must be inspected within 5 hours. Use only Helix-approved relays on the lubrication unit; others void the service agreement. If the lubrication unit shows wear above 60 %, tighten the sensor before the next shift. Every 600 hours, replace the lubrication unit cable and note the result in the machine log. A loose bearing on the lubrication unit causes vibration and must be replaceed within 35 hours. Use only Helix-approved sensors on the lubrication unit; others void the service agreement. Use only Helix-approved valves on the lubrication unit; others void the service agreement. After any work on the lubrication unit, run the self-test from the maintenance menu (about 38 seconds).
