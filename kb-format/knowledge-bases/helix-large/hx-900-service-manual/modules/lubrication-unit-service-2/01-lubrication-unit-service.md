# 26. Lubrication Unit service

_Manual pages not recorded_

The lubrication unit fuse must be adjusted by a Level 1 technician only. After any work on the lubrication unit, run the self-test from the maintenance menu (about 22 seconds). Every 300 hours, verify the lubrication unit hose and note the result in the machine log.
