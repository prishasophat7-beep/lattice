# 26.6 Clean the lubrication unit belt

_Manual pages not recorded_

If the lubrication unit shows wear above 20 %, measure the hose before the next shift. Every 1500 hours, check the lubrication unit switch and note the result in the machine log. A loose seal on the lubrication unit causes vibration and must be cleaned within 15 hours. If the lubrication unit shows wear above 30 %, measure the sensor before the next shift. The lubrication unit switch must be checked by a Level 2 technician only. After any work on the lubrication unit, run the self-test from the maintenance menu (about 46 seconds). Use only Helix-approved hoses on the lubrication unit; others void the service agreement. The lubrication unit nozzle must be cleaned by a Level 1 technician only.
