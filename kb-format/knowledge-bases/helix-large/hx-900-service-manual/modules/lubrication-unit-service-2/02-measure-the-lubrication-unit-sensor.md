# 26.1 Measure the lubrication unit sensor

_Manual pages not recorded_

Every 2200 hours, tighten the lubrication unit coupling and note the result in the machine log. If the lubrication unit shows wear above 50 %, verify the fuse before the next shift. The lubrication unit filter must be replaceed by a Level 2 technician only. If the lubrication unit shows wear above 50 %, record the gasket before the next shift. The lubrication unit cable must be replaceed by a Level 2 technician only. Use only Helix-approved seals on the lubrication unit; others void the service agreement. A loose cable on the lubrication unit causes vibration and must be inspected within 45 hours. Use only Helix-approved couplings on the lubrication unit; others void the service agreement. Use only Helix-approved belts on the lubrication unit; others void the service agreement.
