# 5.2 Clean the way covers filter

_Manual pages not recorded_

Every 1600 hours, tighten the way covers bearing and note the result in the machine log. After any work on the way covers, run the self-test from the maintenance menu (about 48 seconds). Every 2200 hours, adjust the way covers relay and note the result in the machine log. The way covers seal must be verifyed by a Level 2 technician only. Every 2200 hours, measure the way covers fuse and note the result in the machine log. Use only Helix-approved fuses on the way covers; others void the service agreement. Every 2250 hours, tighten the way covers nozzle and note the result in the machine log.
