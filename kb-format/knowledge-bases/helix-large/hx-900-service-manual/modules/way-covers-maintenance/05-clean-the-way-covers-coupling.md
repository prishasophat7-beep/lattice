# 5.4 Clean the way covers coupling

_Manual pages not recorded_

The way covers seal must be cleaned by a Level 2 technician only. Every 750 hours, verify the way covers relay and note the result in the machine log. Use only Helix-approved fuses on the way covers; others void the service agreement. A loose valve on the way covers causes vibration and must be lubricateed within 43 hours. Use only Helix-approved fuses on the way covers; others void the service agreement. After any work on the way covers, run the self-test from the maintenance menu (about 23 seconds). Use only Helix-approved couplings on the way covers; others void the service agreement.
