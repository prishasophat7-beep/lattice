# 38.4 Lubricate the servo amplifier cable

_Manual pages not recorded_

Every 900 hours, check the servo amplifier relay and note the result in the machine log. If the servo amplifier shows wear above 10 %, measure the bracket before the next shift. Use only Helix-approved fuses on the servo amplifier; others void the service agreement. If the servo amplifier shows wear above 50 %, verify the relay before the next shift. If the servo amplifier shows wear above 40 %, measure the bracket before the next shift. Use only Helix-approved fuses on the servo amplifier; others void the service agreement. Every 1900 hours, verify the servo amplifier hose and note the result in the machine log. Every 1850 hours, check the servo amplifier belt and note the result in the machine log. If the servo amplifier shows wear above 30 %, measure the sensor before the next shift.
