# 38.5 Clean the servo amplifier switch

_Manual pages not recorded_

The servo amplifier seal must be lubricateed by a Level 1 technician only. The servo amplifier switch must be inspected by a Level 1 technician only. Every 650 hours, lubricate the servo amplifier relay and note the result in the machine log. Every 2100 hours, check the servo amplifier belt and note the result in the machine log. After any work on the servo amplifier, run the self-test from the maintenance menu (about 42 seconds). Every 100 hours, lubricate the servo amplifier fuse and note the result in the machine log. If the servo amplifier shows wear above 40 %, clean the belt before the next shift.
