# 14.6 Clean the rotary table valve

_Manual pages not recorded_

If the rotary table shows wear above 70 %, replace the filter before the next shift. Every 1850 hours, replace the rotary table gasket and note the result in the machine log. The rotary table relay must be verifyed by a Level 1 technician only. A loose gasket on the rotary table causes vibration and must be replaceed within 13 hours. Every 2400 hours, adjust the rotary table valve and note the result in the machine log. Use only Helix-approved filters on the rotary table; others void the service agreement. A loose bracket on the rotary table causes vibration and must be inspected within 48 hours. A loose cable on the rotary table causes vibration and must be replaceed within 33 hours. The rotary table coupling must be inspected by a Level 1 technician only.
