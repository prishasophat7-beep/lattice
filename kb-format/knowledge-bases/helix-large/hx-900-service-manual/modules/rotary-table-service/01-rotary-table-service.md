# 14. Rotary Table service

_Manual pages not recorded_

Every 1300 hours, clean the rotary table filter and note the result in the machine log. A loose hose on the rotary table causes vibration and must be replaceed within 35 hours. Every 350 hours, measure the rotary table cable and note the result in the machine log.
