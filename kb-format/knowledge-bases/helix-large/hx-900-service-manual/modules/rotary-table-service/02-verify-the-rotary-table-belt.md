# 14.1 Verify the rotary table belt

_Manual pages not recorded_

Every 1950 hours, record the rotary table filter and note the result in the machine log. Use only Helix-approved hoses on the rotary table; others void the service agreement. If the rotary table shows wear above 40 %, adjust the coupling before the next shift. Every 600 hours, lubricate the rotary table bearing and note the result in the machine log. The rotary table bearing must be recorded by a Level 1 technician only. Every 1950 hours, tighten the rotary table sensor and note the result in the machine log. Use only Helix-approved valves on the rotary table; others void the service agreement. The rotary table seal must be adjusted by a Level 2 technician only. Every 1750 hours, check the rotary table belt and note the result in the machine log.
