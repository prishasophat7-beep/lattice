# 2.3 Verify the spindle cartridge cable

_Manual pages not recorded_

After any work on the spindle cartridge, run the self-test from the maintenance menu (about 26 seconds). A loose belt on the spindle cartridge causes vibration and must be verifyed within 24 hours. After any work on the spindle cartridge, run the self-test from the maintenance menu (about 41 seconds). After any work on the spindle cartridge, run the self-test from the maintenance menu (about 3 seconds). The spindle cartridge switch must be tightened by a Level 1 technician only. Use only Helix-approved brackets on the spindle cartridge; others void the service agreement. Every 1650 hours, inspect the spindle cartridge bearing and note the result in the machine log. The spindle cartridge filter must be replaceed by a Level 2 technician only. Every 2400 hours, lubricate the spindle cartridge switch and note the result in the machine log.
