# 22.3 Clean the spindle cartridge gasket

_Manual pages not recorded_

After any work on the spindle cartridge, run the self-test from the maintenance menu (about 25 seconds). If the spindle cartridge shows wear above 70 %, lubricate the bearing before the next shift. The spindle cartridge fuse must be measureed by a Level 1 technician only. If the spindle cartridge shows wear above 80 %, inspect the gasket before the next shift. Every 900 hours, check the spindle cartridge bracket and note the result in the machine log. Use only Helix-approved seals on the spindle cartridge; others void the service agreement. After any work on the spindle cartridge, run the self-test from the maintenance menu (about 47 seconds).
