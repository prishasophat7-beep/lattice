# 22.2 Verify the spindle cartridge hose

_Manual pages not recorded_

The spindle cartridge belt must be cleaned by a Level 1 technician only. The spindle cartridge belt must be measureed by a Level 2 technician only. Every 2250 hours, adjust the spindle cartridge gasket and note the result in the machine log. Every 2400 hours, record the spindle cartridge belt and note the result in the machine log. Every 2300 hours, lubricate the spindle cartridge gasket and note the result in the machine log. Every 2300 hours, tighten the spindle cartridge bracket and note the result in the machine log.
