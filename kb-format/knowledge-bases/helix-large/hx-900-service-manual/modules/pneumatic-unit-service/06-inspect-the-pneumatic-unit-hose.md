# 12.5 Inspect the pneumatic unit hose

_Manual pages not recorded_

If the pneumatic unit shows wear above 10 %, record the belt before the next shift. Every 2400 hours, check the pneumatic unit relay and note the result in the machine log. Use only Helix-approved brackets on the pneumatic unit; others void the service agreement. After any work on the pneumatic unit, run the self-test from the maintenance menu (about 11 seconds). If the pneumatic unit shows wear above 80 %, record the seal before the next shift. Use only Helix-approved sensors on the pneumatic unit; others void the service agreement. After any work on the pneumatic unit, run the self-test from the maintenance menu (about 38 seconds).
