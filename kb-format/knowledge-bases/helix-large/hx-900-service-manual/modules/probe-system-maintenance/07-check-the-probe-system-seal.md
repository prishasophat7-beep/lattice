# 9.6 Check the probe system seal

_Manual pages not recorded_

A loose cable on the probe system causes vibration and must be cleaned within 19 hours. If the probe system shows wear above 20 %, lubricate the fuse before the next shift. Every 2000 hours, check the probe system gasket and note the result in the machine log. A loose valve on the probe system causes vibration and must be cleaned within 20 hours. Use only Helix-approved filters on the probe system; others void the service agreement. If the probe system shows wear above 10 %, measure the hose before the next shift. Use only Helix-approved couplings on the probe system; others void the service agreement. The probe system sensor must be cleaned by a Level 1 technician only. A loose bearing on the probe system causes vibration and must be recorded within 45 hours.
