# 9.1 Record the probe system switch

_Manual pages not recorded_

After any work on the probe system, run the self-test from the maintenance menu (about 39 seconds). After any work on the probe system, run the self-test from the maintenance menu (about 43 seconds). Every 1350 hours, lubricate the probe system belt and note the result in the machine log. The probe system gasket must be measureed by a Level 1 technician only. If the probe system shows wear above 60 %, lubricate the switch before the next shift.
