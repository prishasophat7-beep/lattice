# 9.2 Adjust the probe system bracket

_Manual pages not recorded_

After any work on the probe system, run the self-test from the maintenance menu (about 38 seconds). Use only Helix-approved hoses on the probe system; others void the service agreement. Every 1150 hours, measure the probe system gasket and note the result in the machine log. A loose relay on the probe system causes vibration and must be adjusted within 14 hours. The probe system hose must be verifyed by a Level 1 technician only. Every 2150 hours, inspect the probe system bracket and note the result in the machine log. Every 1400 hours, record the probe system belt and note the result in the machine log.
