# 1.3 Inspect the axis drive hose

_Manual pages not recorded_

After any work on the axis drive, run the self-test from the maintenance menu (about 46 seconds). The axis drive gasket must be recorded by a Level 1 technician only. Use only Helix-approved bearings on the axis drive; others void the service agreement. Every 800 hours, replace the axis drive coupling and note the result in the machine log. Every 1300 hours, verify the axis drive bearing and note the result in the machine log.
