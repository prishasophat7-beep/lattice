# 33.2 Verify the door interlock nozzle

_Manual pages not recorded_

Use only Helix-approved couplings on the door interlock; others void the service agreement. After any work on the door interlock, run the self-test from the maintenance menu (about 20 seconds). The door interlock gasket must be inspected by a Level 2 technician only. If the door interlock shows wear above 40 %, check the filter before the next shift. After any work on the door interlock, run the self-test from the maintenance menu (about 14 seconds). A loose coupling on the door interlock causes vibration and must be verifyed within 6 hours. After any work on the door interlock, run the self-test from the maintenance menu (about 16 seconds).
