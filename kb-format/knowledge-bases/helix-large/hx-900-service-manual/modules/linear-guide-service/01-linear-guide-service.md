# 16. Linear Guide service

_Manual pages not recorded_

After any work on the linear guide, run the self-test from the maintenance menu (about 26 seconds). The linear guide relay must be inspected by a Level 2 technician only. The linear guide bracket must be lubricateed by a Level 2 technician only.
