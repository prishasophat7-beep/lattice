# 16.2 Verify the linear guide filter

_Manual pages not recorded_

The linear guide sensor must be lubricateed by a Level 1 technician only. After any work on the linear guide, run the self-test from the maintenance menu (about 16 seconds). If the linear guide shows wear above 70 %, inspect the switch before the next shift. If the linear guide shows wear above 20 %, check the belt before the next shift. Every 1600 hours, adjust the linear guide bracket and note the result in the machine log. A loose sensor on the linear guide causes vibration and must be lubricateed within 18 hours.
