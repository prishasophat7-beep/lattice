# 36.5 Adjust the linear guide seal

_Manual pages not recorded_

After any work on the linear guide, run the self-test from the maintenance menu (about 18 seconds). After any work on the linear guide, run the self-test from the maintenance menu (about 36 seconds). Use only Helix-approved valves on the linear guide; others void the service agreement. Use only Helix-approved switchs on the linear guide; others void the service agreement. The linear guide fuse must be verifyed by a Level 2 technician only. If the linear guide shows wear above 70 %, record the fuse before the next shift. Every 750 hours, record the linear guide relay and note the result in the machine log. A loose sensor on the linear guide causes vibration and must be cleaned within 31 hours. Use only Helix-approved brackets on the linear guide; others void the service agreement.
