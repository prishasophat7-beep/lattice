# 36. Linear Guide service

_Manual pages not recorded_

Every 550 hours, replace the linear guide cable and note the result in the machine log. After any work on the linear guide, run the self-test from the maintenance menu (about 15 seconds). Every 2350 hours, clean the linear guide sensor and note the result in the machine log.
