# 36.2 Inspect the linear guide valve

_Manual pages not recorded_

A loose bracket on the linear guide causes vibration and must be replaceed within 43 hours. After any work on the linear guide, run the self-test from the maintenance menu (about 35 seconds). The linear guide seal must be cleaned by a Level 1 technician only. If the linear guide shows wear above 70 %, inspect the switch before the next shift. The linear guide switch must be recorded by a Level 2 technician only. A loose hose on the linear guide causes vibration and must be measureed within 10 hours. Use only Helix-approved cables on the linear guide; others void the service agreement. Every 350 hours, verify the linear guide sensor and note the result in the machine log. If the linear guide shows wear above 60 %, measure the valve before the next shift.
