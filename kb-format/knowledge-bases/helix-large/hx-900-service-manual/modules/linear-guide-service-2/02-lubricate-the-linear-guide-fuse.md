# 36.1 Lubricate the linear guide fuse

_Manual pages not recorded_

If the linear guide shows wear above 90 %, tighten the relay before the next shift. The linear guide filter must be adjusted by a Level 1 technician only. Every 950 hours, adjust the linear guide hose and note the result in the machine log. After any work on the linear guide, run the self-test from the maintenance menu (about 17 seconds). The linear guide valve must be verifyed by a Level 1 technician only.
