# 39.4 Measure the chiller belt

_Manual pages not recorded_

Every 1450 hours, check the chiller cable and note the result in the machine log. Use only Helix-approved switchs on the chiller; others void the service agreement. Use only Helix-approved filters on the chiller; others void the service agreement. A loose seal on the chiller causes vibration and must be recorded within 33 hours. After any work on the chiller, run the self-test from the maintenance menu (about 3 seconds).
