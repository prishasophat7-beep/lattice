# 6.2 Check the lubrication unit sensor

_Manual pages not recorded_

After any work on the lubrication unit, run the self-test from the maintenance menu (about 29 seconds). Use only Helix-approved switchs on the lubrication unit; others void the service agreement. If the lubrication unit shows wear above 90 %, measure the fuse before the next shift. Use only Helix-approved relays on the lubrication unit; others void the service agreement. Every 1650 hours, replace the lubrication unit fuse and note the result in the machine log. The lubrication unit coupling must be measureed by a Level 1 technician only. If the lubrication unit shows wear above 20 %, measure the fuse before the next shift. If the lubrication unit shows wear above 10 %, measure the fuse before the next shift.
