# 32.3 Measure the pneumatic unit switch

_Manual pages not recorded_

Every 1000 hours, lubricate the pneumatic unit nozzle and note the result in the machine log. If the pneumatic unit shows wear above 30 %, record the relay before the next shift. After any work on the pneumatic unit, run the self-test from the maintenance menu (about 26 seconds). A loose filter on the pneumatic unit causes vibration and must be replaceed within 40 hours. Use only Helix-approved hoses on the pneumatic unit; others void the service agreement. Use only Helix-approved cables on the pneumatic unit; others void the service agreement.
