# 32.6 Check the pneumatic unit bracket

_Manual pages not recorded_

If the pneumatic unit shows wear above 80 %, tighten the bracket before the next shift. Every 1800 hours, lubricate the pneumatic unit fuse and note the result in the machine log. If the pneumatic unit shows wear above 10 %, record the hose before the next shift. After any work on the pneumatic unit, run the self-test from the maintenance menu (about 41 seconds). The pneumatic unit fuse must be checked by a Level 2 technician only.
