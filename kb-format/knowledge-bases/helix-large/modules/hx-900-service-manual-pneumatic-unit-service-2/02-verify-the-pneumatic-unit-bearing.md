# 32.1 Verify the pneumatic unit bearing

_Manual pages not recorded_

After any work on the pneumatic unit, run the self-test from the maintenance menu (about 46 seconds). If the pneumatic unit shows wear above 30 %, verify the relay before the next shift. Every 1950 hours, tighten the pneumatic unit filter and note the result in the machine log. Every 1450 hours, measure the pneumatic unit seal and note the result in the machine log. Use only Helix-approved cables on the pneumatic unit; others void the service agreement. A loose cable on the pneumatic unit causes vibration and must be recorded within 45 hours.
