# 27.3 Check the hydraulic clamp sensor

_Manual pages not recorded_

After any work on the hydraulic clamp, run the self-test from the maintenance menu (about 22 seconds). After any work on the hydraulic clamp, run the self-test from the maintenance menu (about 14 seconds). The hydraulic clamp bearing must be lubricateed by a Level 1 technician only. The hydraulic clamp bearing must be tightened by a Level 2 technician only. After any work on the hydraulic clamp, run the self-test from the maintenance menu (about 7 seconds). Use only Helix-approved relays on the hydraulic clamp; others void the service agreement. A loose relay on the hydraulic clamp causes vibration and must be replaceed within 37 hours. Use only Helix-approved brackets on the hydraulic clamp; others void the service agreement. If the hydraulic clamp shows wear above 10 %, record the seal before the next shift.
