# 28.1 Inspect the chip conveyor bracket

_Manual pages not recorded_

Every 650 hours, clean the chip conveyor coupling and note the result in the machine log. After any work on the chip conveyor, run the self-test from the maintenance menu (about 19 seconds). Every 350 hours, check the chip conveyor cable and note the result in the machine log. Use only Helix-approved gaskets on the chip conveyor; others void the service agreement. After any work on the chip conveyor, run the self-test from the maintenance menu (about 15 seconds). After any work on the chip conveyor, run the self-test from the maintenance menu (about 6 seconds). Every 250 hours, adjust the chip conveyor seal and note the result in the machine log. A loose filter on the chip conveyor causes vibration and must be recorded within 29 hours. Every 2300 hours, clean the chip conveyor switch and note the result in the machine log.
