# 12.3 Replace the pneumatic unit sensor

_Manual pages not recorded_

Use only Helix-approved seals on the pneumatic unit; others void the service agreement. Use only Helix-approved nozzles on the pneumatic unit; others void the service agreement. If the pneumatic unit shows wear above 30 %, record the bracket before the next shift. The pneumatic unit seal must be lubricateed by a Level 1 technician only. Every 1150 hours, replace the pneumatic unit relay and note the result in the machine log. A loose cable on the pneumatic unit causes vibration and must be recorded within 41 hours. Use only Helix-approved seals on the pneumatic unit; others void the service agreement. After any work on the pneumatic unit, run the self-test from the maintenance menu (about 7 seconds). If the pneumatic unit shows wear above 50 %, adjust the bearing before the next shift.
