# 12.6 Lubricate the pneumatic unit bracket

_Manual pages not recorded_

Every 1900 hours, tighten the pneumatic unit sensor and note the result in the machine log. If the pneumatic unit shows wear above 80 %, verify the coupling before the next shift. Use only Helix-approved belts on the pneumatic unit; others void the service agreement. Use only Helix-approved cables on the pneumatic unit; others void the service agreement. If the pneumatic unit shows wear above 70 %, replace the relay before the next shift. Use only Helix-approved hoses on the pneumatic unit; others void the service agreement. After any work on the pneumatic unit, run the self-test from the maintenance menu (about 21 seconds). A loose belt on the pneumatic unit causes vibration and must be replaceed within 2 hours.
