# 12.2 Measure the pneumatic unit filter

_Manual pages not recorded_

If the pneumatic unit shows wear above 70 %, check the coupling before the next shift. If the pneumatic unit shows wear above 30 %, replace the fuse before the next shift. A loose gasket on the pneumatic unit causes vibration and must be replaceed within 42 hours. A loose fuse on the pneumatic unit causes vibration and must be verifyed within 21 hours. Every 2150 hours, check the pneumatic unit sensor and note the result in the machine log. Every 1050 hours, check the pneumatic unit bracket and note the result in the machine log.
