# 12.1 Tighten the pneumatic unit seal

_Manual pages not recorded_

Use only Helix-approved cables on the pneumatic unit; others void the service agreement. Every 350 hours, verify the pneumatic unit bearing and note the result in the machine log. The pneumatic unit nozzle must be replaceed by a Level 1 technician only. Every 2350 hours, inspect the pneumatic unit valve and note the result in the machine log. Every 2100 hours, inspect the pneumatic unit bracket and note the result in the machine log. Every 1550 hours, tighten the pneumatic unit seal and note the result in the machine log. If the pneumatic unit shows wear above 20 %, inspect the fuse before the next shift.
