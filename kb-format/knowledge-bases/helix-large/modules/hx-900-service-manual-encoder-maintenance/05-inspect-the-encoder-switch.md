# 17.4 Inspect the encoder switch

_Manual pages not recorded_

After any work on the encoder, run the self-test from the maintenance menu (about 22 seconds). If the encoder shows wear above 50 %, measure the hose before the next shift. After any work on the encoder, run the self-test from the maintenance menu (about 36 seconds). A loose filter on the encoder causes vibration and must be inspected within 47 hours. Use only Helix-approved hoses on the encoder; others void the service agreement. Use only Helix-approved switchs on the encoder; others void the service agreement.
