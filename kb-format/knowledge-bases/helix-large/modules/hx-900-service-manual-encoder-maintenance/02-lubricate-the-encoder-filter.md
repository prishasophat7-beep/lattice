# 17.1 Lubricate the encoder filter

_Manual pages not recorded_

After any work on the encoder, run the self-test from the maintenance menu (about 21 seconds). A loose valve on the encoder causes vibration and must be adjusted within 5 hours. Every 100 hours, lubricate the encoder nozzle and note the result in the machine log. After any work on the encoder, run the self-test from the maintenance menu (about 17 seconds). Use only Helix-approved brackets on the encoder; others void the service agreement.
