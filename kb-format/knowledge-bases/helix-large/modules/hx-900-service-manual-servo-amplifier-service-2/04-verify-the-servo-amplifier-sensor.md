# 38.3 Verify the servo amplifier sensor

_Manual pages not recorded_

Use only Helix-approved couplings on the servo amplifier; others void the service agreement. Use only Helix-approved nozzles on the servo amplifier; others void the service agreement. Use only Helix-approved relays on the servo amplifier; others void the service agreement. After any work on the servo amplifier, run the self-test from the maintenance menu (about 14 seconds). The servo amplifier belt must be replaceed by a Level 2 technician only.
