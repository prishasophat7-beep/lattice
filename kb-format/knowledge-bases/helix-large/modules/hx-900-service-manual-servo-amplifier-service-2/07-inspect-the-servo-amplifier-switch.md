# 38.6 Inspect the servo amplifier switch

_Manual pages not recorded_

If the servo amplifier shows wear above 90 %, adjust the seal before the next shift. Use only Helix-approved gaskets on the servo amplifier; others void the service agreement. Use only Helix-approved brackets on the servo amplifier; others void the service agreement. Every 1600 hours, adjust the servo amplifier seal and note the result in the machine log. If the servo amplifier shows wear above 50 %, inspect the filter before the next shift.
