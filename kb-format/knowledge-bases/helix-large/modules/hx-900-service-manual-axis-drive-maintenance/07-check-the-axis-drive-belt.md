# 1.6 Check the axis drive belt

_Manual pages not recorded_

Every 100 hours, record the axis drive sensor and note the result in the machine log. After any work on the axis drive, run the self-test from the maintenance menu (about 11 seconds). The axis drive belt must be cleaned by a Level 2 technician only. If the axis drive shows wear above 30 %, measure the coupling before the next shift. Use only Helix-approved fuses on the axis drive; others void the service agreement.
