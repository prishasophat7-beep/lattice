# 23.2 Verify the coolant pump fuse

_Manual pages not recorded_

The coolant pump belt must be measureed by a Level 2 technician only. A loose bearing on the coolant pump causes vibration and must be replaceed within 3 hours. Use only Helix-approved nozzles on the coolant pump; others void the service agreement. After any work on the coolant pump, run the self-test from the maintenance menu (about 10 seconds). Every 100 hours, measure the coolant pump coupling and note the result in the machine log. Use only Helix-approved brackets on the coolant pump; others void the service agreement. Every 550 hours, inspect the coolant pump gasket and note the result in the machine log. After any work on the coolant pump, run the self-test from the maintenance menu (about 8 seconds).
