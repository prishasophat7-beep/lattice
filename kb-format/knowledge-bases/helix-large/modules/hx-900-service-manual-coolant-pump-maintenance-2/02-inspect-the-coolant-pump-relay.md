# 23.1 Inspect the coolant pump relay

_Manual pages not recorded_

The coolant pump relay must be lubricateed by a Level 2 technician only. Every 2250 hours, replace the coolant pump valve and note the result in the machine log. After any work on the coolant pump, run the self-test from the maintenance menu (about 32 seconds). After any work on the coolant pump, run the self-test from the maintenance menu (about 38 seconds). Every 2150 hours, adjust the coolant pump relay and note the result in the machine log. Every 2100 hours, replace the coolant pump belt and note the result in the machine log. The coolant pump relay must be cleaned by a Level 1 technician only.
