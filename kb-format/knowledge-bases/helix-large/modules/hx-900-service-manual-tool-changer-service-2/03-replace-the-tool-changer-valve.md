# 24.2 Replace the tool changer valve

_Manual pages not recorded_

After any work on the tool changer, run the self-test from the maintenance menu (about 40 seconds). Use only Helix-approved hoses on the tool changer; others void the service agreement. Every 250 hours, check the tool changer cable and note the result in the machine log. If the tool changer shows wear above 10 %, replace the hose before the next shift. The tool changer bearing must be checked by a Level 2 technician only. Use only Helix-approved sensors on the tool changer; others void the service agreement.
