# 24.3 Lubricate the tool changer seal

_Manual pages not recorded_

A loose bearing on the tool changer causes vibration and must be lubricateed within 22 hours. The tool changer cable must be tightened by a Level 2 technician only. Every 1600 hours, lubricate the tool changer coupling and note the result in the machine log. Every 150 hours, verify the tool changer bracket and note the result in the machine log. Every 100 hours, inspect the tool changer coupling and note the result in the machine log.
