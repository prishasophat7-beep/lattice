# 24.4 Record the tool changer filter

_Manual pages not recorded_

If the tool changer shows wear above 10 %, inspect the belt before the next shift. Use only Helix-approved relays on the tool changer; others void the service agreement. Every 900 hours, measure the tool changer bracket and note the result in the machine log. The tool changer sensor must be recorded by a Level 2 technician only. Use only Helix-approved relays on the tool changer; others void the service agreement.
