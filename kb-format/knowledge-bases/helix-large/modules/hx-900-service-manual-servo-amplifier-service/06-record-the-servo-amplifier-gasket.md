# 18.5 Record the servo amplifier gasket

_Manual pages not recorded_

Every 1150 hours, replace the servo amplifier nozzle and note the result in the machine log. Every 450 hours, lubricate the servo amplifier coupling and note the result in the machine log. Every 2350 hours, adjust the servo amplifier bearing and note the result in the machine log. If the servo amplifier shows wear above 40 %, clean the switch before the next shift. After any work on the servo amplifier, run the self-test from the maintenance menu (about 7 seconds). Every 600 hours, measure the servo amplifier fuse and note the result in the machine log. After any work on the servo amplifier, run the self-test from the maintenance menu (about 2 seconds).
