# 40.2 Adjust the mist collector cable

_Manual pages not recorded_

The mist collector switch must be replaceed by a Level 2 technician only. Every 300 hours, clean the mist collector belt and note the result in the machine log. After any work on the mist collector, run the self-test from the maintenance menu (about 31 seconds). Every 1950 hours, verify the mist collector cable and note the result in the machine log. Every 1150 hours, verify the mist collector gasket and note the result in the machine log. Every 550 hours, record the mist collector cable and note the result in the machine log. Use only Helix-approved valves on the mist collector; others void the service agreement.
