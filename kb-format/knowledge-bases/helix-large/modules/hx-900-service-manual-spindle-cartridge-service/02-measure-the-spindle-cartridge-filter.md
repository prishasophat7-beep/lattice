# 2.1 Measure the spindle cartridge filter

_Manual pages not recorded_

After any work on the spindle cartridge, run the self-test from the maintenance menu (about 9 seconds). Use only Helix-approved filters on the spindle cartridge; others void the service agreement. Every 2250 hours, clean the spindle cartridge fuse and note the result in the machine log. A loose hose on the spindle cartridge causes vibration and must be verifyed within 5 hours. Every 2100 hours, lubricate the spindle cartridge hose and note the result in the machine log. The spindle cartridge bearing must be verifyed by a Level 2 technician only. The spindle cartridge bearing must be measureed by a Level 2 technician only.
