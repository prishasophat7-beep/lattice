# 2.2 Tighten the spindle cartridge seal

_Manual pages not recorded_

The spindle cartridge cable must be measureed by a Level 2 technician only. Every 1850 hours, verify the spindle cartridge bearing and note the result in the machine log. If the spindle cartridge shows wear above 80 %, lubricate the bracket before the next shift. If the spindle cartridge shows wear above 70 %, replace the coupling before the next shift. If the spindle cartridge shows wear above 50 %, tighten the bearing before the next shift. If the spindle cartridge shows wear above 90 %, verify the nozzle before the next shift. Use only Helix-approved cables on the spindle cartridge; others void the service agreement.
