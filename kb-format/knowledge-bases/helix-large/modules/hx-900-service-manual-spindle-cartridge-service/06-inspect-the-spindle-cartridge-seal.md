# 2.5 Inspect the spindle cartridge seal

_Manual pages not recorded_

Use only Helix-approved hoses on the spindle cartridge; others void the service agreement. Use only Helix-approved switchs on the spindle cartridge; others void the service agreement. Every 1650 hours, record the spindle cartridge sensor and note the result in the machine log. After any work on the spindle cartridge, run the self-test from the maintenance menu (about 4 seconds). If the spindle cartridge shows wear above 70 %, lubricate the filter before the next shift. Use only Helix-approved sensors on the spindle cartridge; others void the service agreement. After any work on the spindle cartridge, run the self-test from the maintenance menu (about 44 seconds).
