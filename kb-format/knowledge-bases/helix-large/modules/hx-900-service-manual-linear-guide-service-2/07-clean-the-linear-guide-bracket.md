# 36.6 Clean the linear guide bracket

_Manual pages not recorded_

A loose belt on the linear guide causes vibration and must be verifyed within 15 hours. Every 1550 hours, lubricate the linear guide bearing and note the result in the machine log. If the linear guide shows wear above 70 %, tighten the cable before the next shift. After any work on the linear guide, run the self-test from the maintenance menu (about 38 seconds). A loose gasket on the linear guide causes vibration and must be recorded within 48 hours.
