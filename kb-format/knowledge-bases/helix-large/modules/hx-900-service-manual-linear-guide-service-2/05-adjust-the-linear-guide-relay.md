# 36.4 Adjust the linear guide relay

_Manual pages not recorded_

Every 2100 hours, adjust the linear guide cable and note the result in the machine log. The linear guide sensor must be tightened by a Level 1 technician only. Use only Helix-approved bearings on the linear guide; others void the service agreement. Every 1550 hours, check the linear guide seal and note the result in the machine log. Every 300 hours, check the linear guide filter and note the result in the machine log. Use only Helix-approved sensors on the linear guide; others void the service agreement. The linear guide bracket must be inspected by a Level 2 technician only.
