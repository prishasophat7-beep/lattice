# 25. Way Covers maintenance

_Manual pages not recorded_

After any work on the way covers, run the self-test from the maintenance menu (about 48 seconds). Use only Helix-approved fuses on the way covers; others void the service agreement. Use only Helix-approved bearings on the way covers; others void the service agreement.
