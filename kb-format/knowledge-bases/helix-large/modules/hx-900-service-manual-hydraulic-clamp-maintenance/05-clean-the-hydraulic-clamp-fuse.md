# 7.4 Clean the hydraulic clamp fuse

_Manual pages not recorded_

If the hydraulic clamp shows wear above 60 %, tighten the sensor before the next shift. Use only Helix-approved nozzles on the hydraulic clamp; others void the service agreement. Use only Helix-approved relays on the hydraulic clamp; others void the service agreement. The hydraulic clamp cable must be recorded by a Level 2 technician only. Every 2200 hours, measure the hydraulic clamp nozzle and note the result in the machine log. Every 1450 hours, check the hydraulic clamp relay and note the result in the machine log. After any work on the hydraulic clamp, run the self-test from the maintenance menu (about 35 seconds). A loose valve on the hydraulic clamp causes vibration and must be replaceed within 30 hours. The hydraulic clamp sensor must be inspected by a Level 1 technician only.
