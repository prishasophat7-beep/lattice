# 7. Hydraulic Clamp maintenance

_Manual pages not recorded_

Every 1750 hours, check the hydraulic clamp bracket and note the result in the machine log. If the hydraulic clamp shows wear above 30 %, clean the coupling before the next shift. After any work on the hydraulic clamp, run the self-test from the maintenance menu (about 2 seconds).
