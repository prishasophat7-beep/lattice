# 7.1 Replace the hydraulic clamp hose

_Manual pages not recorded_

Use only Helix-approved hoses on the hydraulic clamp; others void the service agreement. After any work on the hydraulic clamp, run the self-test from the maintenance menu (about 36 seconds). If the hydraulic clamp shows wear above 90 %, inspect the cable before the next shift. Every 1550 hours, inspect the hydraulic clamp relay and note the result in the machine log. Use only Helix-approved cables on the hydraulic clamp; others void the service agreement. A loose belt on the hydraulic clamp causes vibration and must be adjusted within 12 hours. Use only Helix-approved seals on the hydraulic clamp; others void the service agreement. Every 150 hours, lubricate the hydraulic clamp switch and note the result in the machine log.
