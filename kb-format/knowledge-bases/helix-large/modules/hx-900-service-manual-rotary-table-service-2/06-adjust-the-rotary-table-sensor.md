# 34.5 Adjust the rotary table sensor

_Manual pages not recorded_

A loose nozzle on the rotary table causes vibration and must be adjusted within 47 hours. After any work on the rotary table, run the self-test from the maintenance menu (about 40 seconds). If the rotary table shows wear above 20 %, replace the bracket before the next shift. Every 1550 hours, clean the rotary table hose and note the result in the machine log. The rotary table bracket must be verifyed by a Level 1 technician only. If the rotary table shows wear above 80 %, lubricate the hose before the next shift.
