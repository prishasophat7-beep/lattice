# 34.1 Record the rotary table nozzle

_Manual pages not recorded_

Every 2150 hours, lubricate the rotary table belt and note the result in the machine log. Use only Helix-approved cables on the rotary table; others void the service agreement. The rotary table hose must be verifyed by a Level 1 technician only. Every 600 hours, verify the rotary table sensor and note the result in the machine log. If the rotary table shows wear above 60 %, measure the relay before the next shift. After any work on the rotary table, run the self-test from the maintenance menu (about 21 seconds).
