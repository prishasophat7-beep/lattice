# 34.2 Inspect the rotary table relay

_Manual pages not recorded_

After any work on the rotary table, run the self-test from the maintenance menu (about 20 seconds). The rotary table cable must be replaceed by a Level 2 technician only. Use only Helix-approved filters on the rotary table; others void the service agreement. Every 1950 hours, verify the rotary table gasket and note the result in the machine log. If the rotary table shows wear above 10 %, check the hose before the next shift. If the rotary table shows wear above 80 %, tighten the seal before the next shift. A loose gasket on the rotary table causes vibration and must be adjusted within 37 hours. A loose hose on the rotary table causes vibration and must be verifyed within 29 hours.
