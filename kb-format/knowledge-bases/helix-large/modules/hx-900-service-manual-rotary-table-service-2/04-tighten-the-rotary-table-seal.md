# 34.3 Tighten the rotary table seal

_Manual pages not recorded_

The rotary table cable must be tightened by a Level 2 technician only. After any work on the rotary table, run the self-test from the maintenance menu (about 6 seconds). Every 900 hours, measure the rotary table fuse and note the result in the machine log. A loose fuse on the rotary table causes vibration and must be measureed within 12 hours. After any work on the rotary table, run the self-test from the maintenance menu (about 19 seconds).
