# 34.4 Check the rotary table switch

_Manual pages not recorded_

Every 1500 hours, tighten the rotary table coupling and note the result in the machine log. A loose fuse on the rotary table causes vibration and must be measureed within 18 hours. After any work on the rotary table, run the self-test from the maintenance menu (about 23 seconds). The rotary table belt must be adjusted by a Level 1 technician only. If the rotary table shows wear above 20 %, lubricate the cable before the next shift. Use only Helix-approved cables on the rotary table; others void the service agreement. Use only Helix-approved switchs on the rotary table; others void the service agreement. If the rotary table shows wear above 60 %, tighten the bearing before the next shift. The rotary table cable must be recorded by a Level 2 technician only.
