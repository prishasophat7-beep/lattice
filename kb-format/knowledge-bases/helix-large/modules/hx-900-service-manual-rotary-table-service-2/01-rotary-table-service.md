# 34. Rotary Table service

_Manual pages not recorded_

If the rotary table shows wear above 80 %, measure the bearing before the next shift. Use only Helix-approved hoses on the rotary table; others void the service agreement. If the rotary table shows wear above 30 %, tighten the relay before the next shift.
