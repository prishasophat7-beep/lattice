# 26.5 Replace the lubrication unit filter

_Manual pages not recorded_

Use only Helix-approved gaskets on the lubrication unit; others void the service agreement. Every 1450 hours, verify the lubrication unit bearing and note the result in the machine log. If the lubrication unit shows wear above 40 %, lubricate the relay before the next shift. Every 400 hours, check the lubrication unit filter and note the result in the machine log. A loose bearing on the lubrication unit causes vibration and must be tightened within 29 hours. The lubrication unit cable must be verifyed by a Level 1 technician only.
