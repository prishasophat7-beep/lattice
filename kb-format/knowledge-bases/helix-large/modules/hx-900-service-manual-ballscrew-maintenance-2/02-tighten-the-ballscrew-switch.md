# 35.1 Tighten the ballscrew switch

_Manual pages not recorded_

Every 1650 hours, lubricate the ballscrew relay and note the result in the machine log. Every 450 hours, tighten the ballscrew gasket and note the result in the machine log. Use only Helix-approved seals on the ballscrew; others void the service agreement. If the ballscrew shows wear above 60 %, record the seal before the next shift. The ballscrew valve must be measureed by a Level 1 technician only. Use only Helix-approved bearings on the ballscrew; others void the service agreement.
