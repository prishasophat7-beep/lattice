# 35.2 Measure the ballscrew bracket

_Manual pages not recorded_

The ballscrew coupling must be tightened by a Level 2 technician only. The ballscrew nozzle must be inspected by a Level 1 technician only. Every 500 hours, inspect the ballscrew cable and note the result in the machine log. The ballscrew coupling must be checked by a Level 2 technician only. If the ballscrew shows wear above 50 %, check the relay before the next shift. After any work on the ballscrew, run the self-test from the maintenance menu (about 7 seconds). Every 1450 hours, tighten the ballscrew cable and note the result in the machine log. After any work on the ballscrew, run the self-test from the maintenance menu (about 3 seconds).
