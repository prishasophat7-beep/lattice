# 4.5 Measure the tool changer switch

_Manual pages not recorded_

Use only Helix-approved seals on the tool changer; others void the service agreement. A loose switch on the tool changer causes vibration and must be verifyed within 25 hours. If the tool changer shows wear above 50 %, inspect the belt before the next shift. Every 1850 hours, record the tool changer sensor and note the result in the machine log. After any work on the tool changer, run the self-test from the maintenance menu (about 19 seconds).
