# 4. Tool Changer service

_Manual pages not recorded_

If the tool changer shows wear above 50 %, record the hose before the next shift. The tool changer nozzle must be checked by a Level 2 technician only. If the tool changer shows wear above 60 %, replace the filter before the next shift.
