# 4.1 Measure the tool changer hose

_Manual pages not recorded_

Use only Helix-approved couplings on the tool changer; others void the service agreement. The tool changer switch must be lubricateed by a Level 2 technician only. Every 1750 hours, measure the tool changer switch and note the result in the machine log. A loose coupling on the tool changer causes vibration and must be tightened within 8 hours. After any work on the tool changer, run the self-test from the maintenance menu (about 9 seconds). Use only Helix-approved fuses on the tool changer; others void the service agreement. After any work on the tool changer, run the self-test from the maintenance menu (about 4 seconds). Use only Helix-approved valves on the tool changer; others void the service agreement.
