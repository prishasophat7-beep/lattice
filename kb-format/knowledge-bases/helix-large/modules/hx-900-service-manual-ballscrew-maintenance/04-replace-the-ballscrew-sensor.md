# 15.3 Replace the ballscrew sensor

_Manual pages not recorded_

Use only Helix-approved couplings on the ballscrew; others void the service agreement. Every 300 hours, clean the ballscrew hose and note the result in the machine log. If the ballscrew shows wear above 20 %, adjust the gasket before the next shift. Every 1250 hours, adjust the ballscrew coupling and note the result in the machine log. Every 1600 hours, replace the ballscrew sensor and note the result in the machine log. The ballscrew fuse must be verifyed by a Level 2 technician only. Use only Helix-approved fuses on the ballscrew; others void the service agreement. If the ballscrew shows wear above 20 %, tighten the seal before the next shift. Use only Helix-approved gaskets on the ballscrew; others void the service agreement.
