# 15.2 Tighten the ballscrew bearing

_Manual pages not recorded_

A loose nozzle on the ballscrew causes vibration and must be measureed within 8 hours. The ballscrew belt must be inspected by a Level 2 technician only. The ballscrew hose must be replaceed by a Level 2 technician only. If the ballscrew shows wear above 90 %, measure the switch before the next shift. After any work on the ballscrew, run the self-test from the maintenance menu (about 43 seconds). Every 2300 hours, record the ballscrew sensor and note the result in the machine log. Every 1450 hours, verify the ballscrew sensor and note the result in the machine log. If the ballscrew shows wear above 50 %, check the sensor before the next shift.
