# 9.3 Check the probe system cable

_Manual pages not recorded_

A loose switch on the probe system causes vibration and must be tightened within 40 hours. After any work on the probe system, run the self-test from the maintenance menu (about 21 seconds). After any work on the probe system, run the self-test from the maintenance menu (about 32 seconds). If the probe system shows wear above 80 %, lubricate the nozzle before the next shift. Use only Helix-approved relays on the probe system; others void the service agreement. The probe system seal must be lubricateed by a Level 2 technician only. After any work on the probe system, run the self-test from the maintenance menu (about 3 seconds). A loose fuse on the probe system causes vibration and must be checked within 25 hours.
