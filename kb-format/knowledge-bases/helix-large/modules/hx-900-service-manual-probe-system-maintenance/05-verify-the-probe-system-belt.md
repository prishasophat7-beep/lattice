# 9.4 Verify the probe system belt

_Manual pages not recorded_

Every 1700 hours, measure the probe system nozzle and note the result in the machine log. Every 2150 hours, record the probe system gasket and note the result in the machine log. A loose cable on the probe system causes vibration and must be checked within 23 hours. The probe system seal must be checked by a Level 1 technician only. Use only Helix-approved seals on the probe system; others void the service agreement. After any work on the probe system, run the self-test from the maintenance menu (about 9 seconds).
