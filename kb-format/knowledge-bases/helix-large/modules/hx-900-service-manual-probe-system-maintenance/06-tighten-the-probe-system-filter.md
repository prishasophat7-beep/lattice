# 9.5 Tighten the probe system filter

_Manual pages not recorded_

A loose sensor on the probe system causes vibration and must be tightened within 9 hours. A loose cable on the probe system causes vibration and must be measureed within 20 hours. Every 2250 hours, record the probe system gasket and note the result in the machine log. Every 350 hours, check the probe system bearing and note the result in the machine log. Every 1200 hours, check the probe system bracket and note the result in the machine log. A loose seal on the probe system causes vibration and must be adjusted within 41 hours. Every 500 hours, check the probe system sensor and note the result in the machine log. A loose bearing on the probe system causes vibration and must be tightened within 39 hours. A loose fuse on the probe system causes vibration and must be lubricateed within 44 hours.
