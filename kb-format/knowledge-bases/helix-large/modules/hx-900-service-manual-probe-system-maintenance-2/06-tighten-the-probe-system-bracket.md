# 29.5 Tighten the probe system bracket

_Manual pages not recorded_

Every 750 hours, tighten the probe system cable and note the result in the machine log. The probe system filter must be lubricateed by a Level 2 technician only. Use only Helix-approved nozzles on the probe system; others void the service agreement. Use only Helix-approved nozzles on the probe system; others void the service agreement.
