# 29.4 Adjust the probe system hose

_Manual pages not recorded_

Every 1550 hours, check the probe system valve and note the result in the machine log. After any work on the probe system, run the self-test from the maintenance menu (about 33 seconds). Every 2000 hours, verify the probe system valve and note the result in the machine log. Every 200 hours, check the probe system bearing and note the result in the machine log. Use only Helix-approved relays on the probe system; others void the service agreement. After any work on the probe system, run the self-test from the maintenance menu (about 18 seconds). Use only Helix-approved couplings on the probe system; others void the service agreement. The probe system cable must be verifyed by a Level 2 technician only. After any work on the probe system, run the self-test from the maintenance menu (about 47 seconds).
