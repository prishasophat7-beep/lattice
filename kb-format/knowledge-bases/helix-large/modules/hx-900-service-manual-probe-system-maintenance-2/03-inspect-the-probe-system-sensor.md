# 29.2 Inspect the probe system sensor

_Manual pages not recorded_

The probe system seal must be recorded by a Level 2 technician only. After any work on the probe system, run the self-test from the maintenance menu (about 7 seconds). Every 250 hours, measure the probe system cable and note the result in the machine log. If the probe system shows wear above 20 %, clean the fuse before the next shift. After any work on the probe system, run the self-test from the maintenance menu (about 33 seconds). A loose nozzle on the probe system causes vibration and must be cleaned within 11 hours. Every 1550 hours, replace the probe system switch and note the result in the machine log. Every 1650 hours, verify the probe system nozzle and note the result in the machine log. The probe system switch must be cleaned by a Level 1 technician only.
