# 29.1 Inspect the probe system filter

_Manual pages not recorded_

If the probe system shows wear above 80 %, inspect the bracket before the next shift. A loose sensor on the probe system causes vibration and must be checked within 13 hours. A loose valve on the probe system causes vibration and must be replaceed within 20 hours. Use only Helix-approved hoses on the probe system; others void the service agreement. If the probe system shows wear above 50 %, inspect the bearing before the next shift. After any work on the probe system, run the self-test from the maintenance menu (about 8 seconds). A loose coupling on the probe system causes vibration and must be measureed within 6 hours. If the probe system shows wear above 60 %, tighten the relay before the next shift.
