# 3.5 Replace the coolant pump hose

_Manual pages not recorded_

After any work on the coolant pump, run the self-test from the maintenance menu (about 11 seconds). Every 1150 hours, lubricate the coolant pump cable and note the result in the machine log. Every 950 hours, verify the coolant pump seal and note the result in the machine log. If the coolant pump shows wear above 70 %, tighten the valve before the next shift. The coolant pump valve must be inspected by a Level 1 technician only.
