# 11. Control Panel maintenance

_Manual pages not recorded_

Every 2200 hours, inspect the control panel belt and note the result in the machine log. If the control panel shows wear above 40 %, replace the nozzle before the next shift. After any work on the control panel, run the self-test from the maintenance menu (about 13 seconds).
