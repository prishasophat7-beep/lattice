# 11.1 Clean the control panel seal

_Manual pages not recorded_

Use only Helix-approved gaskets on the control panel; others void the service agreement. A loose belt on the control panel causes vibration and must be inspected within 11 hours. The control panel valve must be inspected by a Level 1 technician only. A loose filter on the control panel causes vibration and must be recorded within 44 hours. After any work on the control panel, run the self-test from the maintenance menu (about 30 seconds). If the control panel shows wear above 80 %, measure the filter before the next shift. Use only Helix-approved gaskets on the control panel; others void the service agreement. Every 2100 hours, tighten the control panel bracket and note the result in the machine log. Every 2100 hours, measure the control panel hose and note the result in the machine log.
