# 16.6 Inspect the linear guide relay

_Manual pages not recorded_

After any work on the linear guide, run the self-test from the maintenance menu (about 22 seconds). A loose belt on the linear guide causes vibration and must be lubricateed within 13 hours. If the linear guide shows wear above 70 %, adjust the cable before the next shift. If the linear guide shows wear above 10 %, adjust the nozzle before the next shift. Use only Helix-approved gaskets on the linear guide; others void the service agreement.
