# 16.5 Tighten the linear guide seal

_Manual pages not recorded_

A loose coupling on the linear guide causes vibration and must be tightened within 31 hours. After any work on the linear guide, run the self-test from the maintenance menu (about 44 seconds). A loose filter on the linear guide causes vibration and must be adjusted within 42 hours. After any work on the linear guide, run the self-test from the maintenance menu (about 43 seconds). If the linear guide shows wear above 20 %, lubricate the hose before the next shift. Use only Helix-approved brackets on the linear guide; others void the service agreement. Use only Helix-approved switchs on the linear guide; others void the service agreement.
