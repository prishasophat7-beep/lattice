# 16.4 Clean the linear guide belt

_Manual pages not recorded_

The linear guide filter must be lubricateed by a Level 1 technician only. Every 2150 hours, check the linear guide belt and note the result in the machine log. The linear guide fuse must be verifyed by a Level 1 technician only. Every 100 hours, lubricate the linear guide hose and note the result in the machine log. A loose hose on the linear guide causes vibration and must be adjusted within 33 hours. A loose cable on the linear guide causes vibration and must be lubricateed within 11 hours. The linear guide sensor must be replaceed by a Level 1 technician only. A loose hose on the linear guide causes vibration and must be inspected within 10 hours.
