# 14.5 Inspect the rotary table cable

_Manual pages not recorded_

Every 1300 hours, verify the rotary table relay and note the result in the machine log. The rotary table fuse must be adjusted by a Level 1 technician only. A loose filter on the rotary table causes vibration and must be adjusted within 44 hours. If the rotary table shows wear above 80 %, measure the switch before the next shift. If the rotary table shows wear above 70 %, record the fuse before the next shift. After any work on the rotary table, run the self-test from the maintenance menu (about 13 seconds). After any work on the rotary table, run the self-test from the maintenance menu (about 47 seconds). If the rotary table shows wear above 80 %, lubricate the valve before the next shift. A loose cable on the rotary table causes vibration and must be lubricateed within 37 hours.
