# 14.3 Record the rotary table gasket

_Manual pages not recorded_

A loose switch on the rotary table causes vibration and must be replaceed within 37 hours. After any work on the rotary table, run the self-test from the maintenance menu (about 39 seconds). Use only Helix-approved sensors on the rotary table; others void the service agreement. The rotary table bracket must be inspected by a Level 2 technician only. Every 1850 hours, clean the rotary table coupling and note the result in the machine log. Every 900 hours, lubricate the rotary table belt and note the result in the machine log. Use only Helix-approved switchs on the rotary table; others void the service agreement. If the rotary table shows wear above 30 %, inspect the valve before the next shift.
