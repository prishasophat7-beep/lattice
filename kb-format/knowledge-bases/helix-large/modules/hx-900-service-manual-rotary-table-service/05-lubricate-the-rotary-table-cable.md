# 14.4 Lubricate the rotary table cable

_Manual pages not recorded_

A loose valve on the rotary table causes vibration and must be inspected within 8 hours. Use only Helix-approved switchs on the rotary table; others void the service agreement. If the rotary table shows wear above 60 %, check the filter before the next shift. A loose filter on the rotary table causes vibration and must be tightened within 48 hours. Every 1200 hours, adjust the rotary table bracket and note the result in the machine log. Use only Helix-approved hoses on the rotary table; others void the service agreement. Use only Helix-approved hoses on the rotary table; others void the service agreement. Every 550 hours, clean the rotary table seal and note the result in the machine log.
