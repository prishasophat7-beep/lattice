# Firmware release notes v3 2

Source file: `firmware_release_notes_v3_2.docx`

Summarizes the headline changes in 3.2.0: Adaptive Recovery, monthly energy reports, faster boot and a power-stealing stability fix. Describes the two new features in detail. Lists six fixed issues with their ticket IDs, including E2 brown-outs and schedule drift across daylight saving changes. Lists open issues in 3.2.0 such as a missing display calibration table warning and slow reports for heat pump systems.
