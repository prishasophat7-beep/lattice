# 2.2 Wireless Connectivity

_Manual p. 2_

Wireless connectivity uses a pre-certified ESP32-C6-MINI module with an on-board PCB antenna. The antenna keep-out area must be at least 15 mm from the relay board and any metal backplate. BLE is used during setup for commissioning from the Nimbus mobile app; Wi-Fi is used for cloud connectivity and firmware updates.
