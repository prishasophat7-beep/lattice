# Adaptive Recovery

_Manual pages not recorded_

Adaptive Recovery observes how quickly the home heats and cools over the first 7 days after it is enabled. It then starts heating or cooling ahead of each schedule change so the target is reached on time. Early start is capped at 2 hours and is disabled in Eco mode. The feature is on by default for new installs and off by default for existing users, who will be prompted in the app.
