# 4.1 Modes

_Manual p. 3_

| Mode | What it does | Best for |
| --- | --- | --- |
| Heat | Heats to the set temperature | Winter |
| Cool | Cools to the set temperature | Summer |
| Auto | Keeps temperature between a low and high set point | Spring and fall |
| Eco | Uses wider set points when nobody is home | Saving energy |
| Off | Heating and cooling are off; fan can still run | Open-window days |
