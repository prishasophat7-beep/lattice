# X2 installation and user guide

Source file: `x2_installation_and_user_guide.pdf` · 4 pages

Gives the key electrical safety warnings, including switching off power at the breaker and not using X2 with line-voltage systems. Lists the package contents: thermostat, backplate, trim plate, screws, labels and the optional C-wire adapter. Walks through wiring and mounting the thermostat, typically taking about 30 minutes. Describes the home screen, the available operating modes and how to set schedules. Shows an example error screen and a table of error codes E1-E6 with causes and fixes.
