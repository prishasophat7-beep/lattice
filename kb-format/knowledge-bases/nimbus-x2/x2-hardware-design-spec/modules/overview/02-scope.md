# 1.1 Scope

_Manual p. 1_

This document covers the main board (PCB-X2-MB), the relay board (PCB-X2-RB) and the interface between them. Firmware behavior is specified in FW-X2-004 and enclosure tooling in ME-X2-002. All voltages are nominal unless stated otherwise.
