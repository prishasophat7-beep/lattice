# Software Catalog

_Manual pages not recorded_

| Application | Used for | How to get it |
| --- | --- | --- |
| Slack | Chat and announcements | Pre-installed |
| Google Workspace | Email, calendar, docs | Web, via SSO |
| Zoom | Video meetings | Pre-installed |
| 1Password | Password manager | Pre-installed; team vaults assigned by manager |
| Jira and Confluence | Tickets and documentation | Web, via SSO |
| GitHub Enterprise | Source code (engineering) | Request in #it-help |
| Figma | Design | Request in #it-help |

To request other software, open a ticket in the IT portal. Requests are reviewed by Security within 2 business days.
