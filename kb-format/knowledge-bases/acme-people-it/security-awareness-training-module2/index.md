# Security awareness training module2

Source file: `security_awareness_training_module2.docx`

Explains that phishing caused most security incidents at Acme in 2025 and why every employee is a target. Walks through an annotated fake payroll email and the four red flags it contains. Explains how to use the Report Phish button and what to do if you already clicked a link. Recommends passphrases, the password manager and never reusing work passwords. Includes a photo of the whiteboard from the August phishing workshop listing red flags and the next session date.
