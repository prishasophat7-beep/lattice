# Integrations

_Manual pages not recorded_

Admins connect integrations from **Settings > Workspace > Integrations**:

- **Slack / Microsoft Teams** - post task updates to channels.
- **GitHub / GitLab** - link commits and pull requests via task keys such as `WEB-142` in commit messages.
- **Google Calendar / Outlook** - sync due dates.
- **Jira import** - migrate projects, issues and attachments.

Each integration uses OAuth 2.0; tokens can be revoked at any time from the same page.
