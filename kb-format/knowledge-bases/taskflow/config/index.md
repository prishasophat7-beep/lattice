# Config

Source file: `config.xml`

IntelliJ-style project code style configuration (scheme 'Project', version 173) stored as XML. It enables spaces inside empty HTML tags and enforced attribute quotes, and for JavaScript forces semicolons and disables the space before function parentheses.
