# About

_Manual pages not recorded_

TaskFlow Pro 4.2 is a collaborative project management application for teams of 5 to 500 people. It combines Kanban boards, Gantt timelines, time tracking and reporting in a single workspace, and is available as a browser application and as a desktop client for Windows and macOS.

This manual is written for project managers, team members and workspace administrators. Administrator-only features are marked **(Admin)**.
