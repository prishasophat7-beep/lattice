# Requirements

_Manual pages not recorded_

| Component | Minimum | Recommended |
|---|---|---|
| Browser | Chrome 118, Edge 118, Firefox 120, Safari 17 | Latest stable release |
| Desktop OS | Windows 10 (22H2), macOS 13 Ventura | Windows 11, macOS 15 |
| Memory | 4 GB RAM | 8 GB RAM |
| CPU | Dual-core 2.0 GHz | Quad-core 2.5 GHz |
| Network | 2 Mbps, ports 443 and 8443 open | 10 Mbps |

Screen resolution of at least 1366 x 768 is required; Gantt view is best used at 1920 x 1080 or higher.
