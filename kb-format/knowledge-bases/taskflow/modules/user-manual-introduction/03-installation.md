# Installation

_Manual pages not recorded_

**Web:** Open `https://app.taskflowpro.example` and sign in with your work email or your organisation's SSO provider.

**Desktop client:**

1. Download `TaskFlowPro-Setup-4.2.0.exe` (Windows) or `TaskFlowPro-4.2.0.dmg` (macOS) from the Help > Downloads page.
2. Run the installer and accept the default install location.
3. Launch TaskFlow Pro and enter your workspace URL, e.g. `acme.taskflowpro.example`.
4. Sign in. On first launch, the setup wizard asks for your time zone and default notification preferences.

Silent install for IT departments: `TaskFlowPro-Setup-4.2.0.exe /S /D=C:\Apps\TaskFlowPro`.
